# Sales Performance Dashboard

## Project Overview

The Sales Performance Dashboard is an interactive dashboard developed using Microsoft Excel and Power BI to analyze and visualize sales data.

The dashboard provides insights into employee sales performance, department-wise sales, and city-wise sales through interactive charts, cards, and filters.

## Objectives

* Clean and preprocess sales data
* Handle missing and inconsistent data
* Check and remove duplicate records
* Calculate total and average sales
* Analyze department-wise sales performance
* Analyze city-wise sales performance
* Create interactive visual reports using Power BI

## Tools and Technologies

* Microsoft Excel - Data cleaning and preprocessing
* Power BI - Data visualization and dashboard development
* GitHub - Project version control and documentation

## Dashboard Features

* Total Sales
* Average Sales
* Highest Sale
* Lowest Sale
* Department-wise Sales
* City-wise Sales
* Employee-wise Sales
* Interactive Department and City filters
* Sales performance analysis

## Data Processing

The data was processed through the following steps:

1. Checked for duplicate records
2. Identified missing values
3. Handled missing sales values
4. Checked inconsistent city names
5. Standardized city names
6. Corrected date formatting
7. Calculated sales metrics
8. Created visualizations and dashboard

## Dashboard

The Power BI dashboard provides an interactive view of overall sales performance and allows users to filter the data based on different categories.
